# Skull Online

Chạy thử trên máy:
    npm install
    npm start        # mở http://localhost:3000

Deploy miễn phí (Render / Railway / Fly.io): đẩy thư mục này lên GitHub,
tạo Web Service Node, Build: `npm install`, Start: `npm start`. Server dùng biến PORT tự động.
